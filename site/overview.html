统一网络

全部 25 个服务接入自定义网络 basic-net，容器之间一律用服务名互访。业务容器需先接入才能直连：docker network connect basic-net <业务容器名>。

统一密码

所有设置了密码的组件，初始密码统一为 admin123。仅限本机 / 局域网使用，请勿将端口暴露到公网。

数据全落盘

数据 / 日志统一落在 D:\local\basic-service-data 对应子目录，备份 = 先停服再复制目录。例外：ClickHouse / GitLab 因 Windows 目录挂载不兼容，数据存 Docker 卷 basic-service_clickhouse_* / basic-service_gitlab_*。

跨项目互通

中间件额外接入外部项目网络，对方容器用容器名即可直连：
esg（esg-uat_esg）：11 个中间件全接入；
qdata（docker_qdatanet）：除 mysql / redis / rabbitmq / neo4j 外 7 个接入——这四个在对方网络存在同名别名，接入会造成 DNS 解析错乱。

端口已避让

常用端口已避开本机占用：MySQL 23306、Redis 26379、PostgreSQL 15432、RabbitMQ 25672/25673、Neo4j 17474/17687 等。统一用 127.0.0.1 访问（本机 ::1 部分端口被其他进程占用）。

发布页

站点发布 / 同步说明见发布页：publish.html。总览页与发布页经 nginx 同源发布于 http://127.0.0.1/（先运行 scripts\sync-site.bat 同步）。
